# Agentic Airbnb - AI Travel Concierge

This repository contains the Agentic Airbnb AI Travel Concierge system - an intelligent AI-powered travel planning service for Airbnb guests.

## 📁 Repository Structure

```
agentic-airbnb/
└── agent/                    # Main application directory
    ├── app/                  # FastAPI application
    ├── requirements.txt      # Dependencies
    ├── README.md           # Detailed documentation
    ├── run_server_sqlite.py # Server startup
    ├── setup_sqlite.py     # Database setup
    └── test_api.py         # API tests
```

## 🚀 Quick Start

1. **Navigate to the agent directory:**
   ```bash
   cd agent/
   ```

2. **Follow the setup instructions in the agent README:**
   ```bash
   cat README.md
   ```

3. **Or visit the detailed documentation:**
   - [Agent Documentation](./agent/README.md)

## 📋 Features

- **AI-Powered Travel Planning** with LangChain
- **Natural Language Processing** for travel requests
- **Day-by-Day Itinerary Planning**
- **Smart Activity & Restaurant Recommendations**
- **Weather-Aware Packing Lists**
- **Real-time Web Search Integration** with Tavily
- **Comprehensive API Documentation**

## 🛠️ Technology Stack

- **Backend:** FastAPI + Python
- **AI/ML:** LangChain + OpenAI
- **Database:** SQLite
- **Web Search:** Tavily API
- **Documentation:** OpenAPI/Swagger
